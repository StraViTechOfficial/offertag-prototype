Pinned board

Pinned deals show on the Top deals page only, in a repeating slot every few cards, all the way down the feed. Slot 1 is the first pinned spot, slot 2 the next, and so on. Drag a card to change the order; dropping on another card swaps the two.Change the order with the slot menu on each card; picking a filled slot swaps the two. When pinned deals run out, the rest of the slots show normal fresh deals.

Preview on Top deals

Keyboard: focus a card, press Space to pick it up, arrow keys to move, Space to drop. On a phone, use the slot menu on each card.
