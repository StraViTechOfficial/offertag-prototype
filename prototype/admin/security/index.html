Security

Tools for when fake visitors flood the site. Real visitors, Google and Shop Now keep working.

Bot check

Sample
Bot check for all visitorsEvery visitor to a web page passes Cloudflare’s automatic check first. Real visitors see a 1–3 second check. Google, Bing, Shop Now links and the app are never affected.
Off

The bot check is on. Every visitor waits 1–3 seconds before a page opens. Turn it off when the site is back to normal.

Turn it on when the site slows down from a flood of fake visits. It starts in about 25 seconds and stops in about 15.

Flagged IPs

An IP with over 300 Shop Now clicks in 10 minutes is flagged. It still reaches the store, but without our Amazon tag, and its clicks don’t count as views. Nothing is blocked. A flag clears itself after a day.

IPStatusWhyAddedUntilAction

No flagged IPs. A visitor with over 300 Shop Now clicks in 10 minutes shows up here.

Many mobile users in India share one IP, so one flagged IP can be hundreds of real people. Let an IP back in when real shoppers are caught by mistake.
